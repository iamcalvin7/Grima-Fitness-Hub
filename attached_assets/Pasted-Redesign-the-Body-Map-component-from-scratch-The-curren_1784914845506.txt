Redesign the Body Map component from scratch.

The current version is too simplistic, geometric and mannequin-like. It uses blocky limbs, a circular head and unrealistic proportions. Do not refine or restyle the existing body illustration. Replace it completely.

## Core Requirement

Find a high-quality open-source anatomical SVG in a style similar to MuscleWiki, import it into the project, separate every muscle group into its own SVG path, and recolour it to match my brand.

Do not draw a new human body using basic rectangles, circles, polygons or simplified geometric shapes.

Before using any asset:

- Confirm that it is genuinely open source
- Confirm that its licence allows commercial use and modification
- Record the asset source and licence in the project
- Add the attribution required by the licence
- Do not use or copy proprietary MuscleWiki artwork; use it only as a quality and style reference

If a suitable commercially usable anatomical SVG cannot be found, stop and clearly explain the limitation instead of generating another simplified mannequin.

## Desired Quality

The body map should resemble the anatomy illustrations used in premium fitness applications.

It must include:

- Realistic athletic male anatomy
- Natural human proportions
- Anatomically accurate muscle placement
- Proper head, neck and shoulder structure
- Defined chest and torso
- Natural waist and hips
- Realistic arms and forearms
- Proper hands and fingers
- Realistic thighs, knees, calves and feet
- Smooth organic vector curves
- Clear separation between muscle groups
- Front and back body views

The body must look human, not robotic, cartoonish or diagrammatically blocky.

## SVG Structure

Convert the imported anatomy artwork into a reusable inline SVG React component.

Each selectable muscle group must have:

- Its own SVG path or grouped SVG paths
- A stable and descriptive ID
- A shared `data-muscle` attribute
- Independent hover and selected states
- A sufficiently large click or tap target
- Keyboard accessibility where practical

Use grouped paths when one muscle appears on both sides of the body.

Example:

```html
<g id="chest" data-muscle="chest">
  <!-- left and right pectoral paths -->
</g>

Do not use one flattened image for the entire body.
