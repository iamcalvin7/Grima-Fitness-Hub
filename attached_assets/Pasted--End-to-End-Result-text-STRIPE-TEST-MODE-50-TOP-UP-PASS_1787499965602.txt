## Defect Found and Fixed

**Symptom:** The first Sandbox payment returned successfully from Stripe but left the wallet pending at €0.00.

**Root cause:** A webhook secret was configured, so the application skipped managed-webhook registration. The Stripe Test Mode account had no active webhook endpoint, so Stripe never delivered the signed event.

**Smallest fix:** The API now always registers/reuses the managed Stripe Test Mode webhook at startup and uses its stored endpoint-specific signing secret for validation.
