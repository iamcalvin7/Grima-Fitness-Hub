# 2. Fix the media-reference indicator

Correct the exercise-card media state so that:

* An exercise with a valid `mediaUrl` displays **Reference linked**.
* An exercise without a media reference displays **No reference**.
* Missing and linked states are not inverted.
* The display does not claim that a remote resource successfully loaded unless it was actually loaded.
* No upload pipeline or new media service is introduced.

Add focused regression tests proving both states.

---

# 3. Implement accessible editor-dialog focus management

The Exercise Library editor currently declares:

```text
role="dialog"
aria-modal="true"
```

Complete the corresponding keyboard and focus behavior.

Requirements:

* Move focus into the dialog when it opens.
* Focus an appropriate first control or the dialog heading/container.
* Keep Tab and Shift+Tab focus within the open modal.
* Close the dialog with Escape when closing is safe.
* If unsaved changes exist, Escape must follow the existing unsaved-change confirmation behavior rather than silently discard changes.
* Restore focus to the control that opened the dialog after it closes.
* Prevent meaningful keyboard interaction with background page controls while the modal is open.
* Preserve existing click/touch closing behavior.
* Preserve existing unsaved-change protection.
* Do not create nested or conflicting keyboard handlers.
* Do not break form inputs, BodyMap keyboard interaction, confirmation controls, or lifecycle actions.

Use an existing accessible dialog primitive if the application already has one and it can be adopted without unrelated refactoring. Otherwise implement the smallest reusable focus-management solution needed for this editor.

Add deterministic tests covering:

* Initial focus inside the dialog.
* Tab wrapping from the last focusable control to the first.
* Shift+Tab wrapping from the first control to the last.
* Escape close with a clean form.
* Escape with unsaved changes invoking the existing confirmation protection.
* Focus restoration to the opener after close.
