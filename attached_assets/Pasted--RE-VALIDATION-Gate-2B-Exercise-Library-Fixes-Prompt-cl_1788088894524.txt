# 2. Media-reference fix

Inspect the final exercise-card condition and its tests.

Confirm:

* A non-empty valid `mediaUrl` displays **Reference linked**.
* A missing, empty or whitespace-only `mediaUrl` displays **No reference**.
* The states are no longer inverted.
* The label confirms only the existence of a stored reference.
* The UI does not imply that the remote resource loaded successfully.
* No fake upload, storage or media-validation service was introduced.
* Both linked and missing cases have direct committed regression tests.

# 3. Dialog focus-management validation

Inspect the complete editor-dialog implementation, including opening, closing, keyboard handling and unmount behavior.

Confirm:

* Focus moves inside the dialog when it opens.
* The initial focus target is deterministic and accessible.
* Tab from the final focusable control wraps to the first.
* Shift+Tab from the first focusable control wraps to the final control.
* Keyboard focus cannot escape into meaningful background controls while the dialog is open.
* Escape closes a clean editor.
* Escape on a dirty editor uses the established unsaved-change confirmation.
* Rejecting that confirmation leaves the editor open and preserves the entered values.
* Confirming it closes the editor.
* Focus returns to the exact New Exercise or Edit control that opened the dialog.
* Click and touch closing behavior remains intact.
* Browser-refresh protection remains intact.
* BodyMap keyboard interaction is not intercepted incorrectly.
* Input, selector, confirmation and lifecycle controls remain keyboard-operable.
* Event listeners are removed correctly when the dialog closes or unmounts.
* No duplicate or conflicting keyboard handler remains.
* Dialog semantics and accessible labelling remain correct.

Inspect the tests and confirm direct coverage for:

* Initial focus
* Forward Tab wrapping
* Reverse Tab wrapping
* Clean Escape closing
* Dirty Escape confirmation
* Rejected dirty-close preservation
* Opener focus restoration

Do not accept the presence of event-handler code alone as proof. Confirm the behavior and tests agree.
